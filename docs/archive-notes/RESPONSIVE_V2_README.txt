Crafted Visual Responsive V2 Fix

This package embeds the responsive mobile/tablet/desktop rules directly into styles.css and script.js, so changes work even if separate folders/files are missed during GitHub upload.

Visible changes to test:
1. On mobile width under 760px, header becomes hamburger menu.
2. Mobile bottom navigation appears: Home / Shop / Cart / Account.
3. Product detail modal becomes bottom sheet.
4. Add-to-cart becomes sticky at bottom on mobile product details.
5. Shop/product grids become one-column on mobile and responsive on tablet.
6. Touch buttons are larger for color, size, and fabric.

After deploying to Railway, hard refresh:
Mac Chrome: Cmd + Shift + R
Mobile Safari/Chrome: clear browser cache or open private tab.
