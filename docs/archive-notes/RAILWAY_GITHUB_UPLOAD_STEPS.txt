GITHUB UPLOAD STEPS
1. Unzip this file.
2. Open your GitHub repository.
3. Upload all files and folders from this unzipped folder to the repository root.
4. Make sure package.json, railway.json, backend folder, admin.html, shop.html, index.html are in the root.
5. Commit changes.

RAILWAY DEPLOY STEPS
1. Open Railway.
2. Create New Project.
3. Choose Deploy from GitHub repo.
4. Select this repository.
5. Railway will detect Node.js.
6. Start command is already set in railway.json: npm start
7. Wait for deployment to finish.
8. Open the generated Railway domain.

TESTING AFTER DEPLOYMENT
1. Open: https://your-railway-domain/admin.html
2. Login as Super Admin.
3. Go to Products.
4. Add a product.
5. Save Product.
6. Open: https://your-railway-domain/shop.html
7. The product should appear from the live backend.

NOTES
- This version uses a server backend with SQLite for Railway prototype/demo deployment.
- Products, admin users, orders, CRM and finance data will save on the server.
- For a final commercial launch, PostgreSQL is recommended instead of SQLite.
