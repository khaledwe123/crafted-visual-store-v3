Prototype product preview instructions

This version is still static/prototype only. It does not use a live database yet.

To preview products added from Super Admin:
1. Open admin.html.
2. Add your product and save it.
3. In the Products panel, click Open Shop Preview.
4. The shop page will open and receive the products directly from Super Admin.

Do not manually open shop.html and expect the product to appear in every case when using file:/// local files. Browsers may isolate local file storage. Use the Open Shop Preview button for the prototype.

When you connect a live database later, products will publish normally from Admin to Shop.
