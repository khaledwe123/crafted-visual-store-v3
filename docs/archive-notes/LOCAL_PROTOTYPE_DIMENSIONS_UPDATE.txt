Latest prototype update:
- Product detail now shows size choices as dimensions.
- Dimensions display as Width × Depth × Height in cm.
- The selected dimensions are shown clearly under the VAT-included price.
- Add to Cart and WhatsApp enquiry now use dimensions instead of size label.

How to test:
1. Open admin.html.
2. Go to Products.
3. Add product.
4. Add size name plus Width, Depth, Height.
5. Add fabric and price.
6. Save Product.
7. Click Open Shop Preview.
8. Click View Details.
9. Dimensions should appear instead of King / Super King labels.
