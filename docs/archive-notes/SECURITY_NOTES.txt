Security hardening added in this version:

1. JWT secret moved to Railway Variables.
2. Admin email/password can be controlled from Railway Variables.
3. Login rate limit added.
4. General API rate limit added.
5. Safer upload handling:
   - Maximum upload size: 5 MB by default.
   - Allowed types: JPG, PNG, WEBP, GIF, PDF.
   - Random server-side filenames.
6. Helmet security headers added.
7. CORS can be limited with ALLOWED_ORIGINS.
8. Admin pages are served with no-store cache headers.
9. Basic input length cleaning added.
10. Node pinned to version 20.x.

Railway Variables to add before going live:

NODE_ENV=production
JWT_SECRET=use-a-long-random-secret-at-least-32-characters
ADMIN_EMAIL=your-admin-email
ADMIN_PASSWORD=your-strong-admin-password

Important:
This is safer, but for a real live ecommerce business you should still move from SQLite to PostgreSQL, add real payment gateway security, backup policy, audit logs, and privacy/terms pages.
